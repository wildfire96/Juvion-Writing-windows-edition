# Juvion para Windows

Baixe a versão portátil para Windows em **Releases**: [versão mais recente](https://github.com/wildfire96/Juvion-Writing-windows-edition/releases/latest).

## Instalação

1. Baixe `Juvion_v1.0.1_Windows_Portable.zip` nos arquivos da versão.
2. Extraia o ZIP inteiro para uma pasta onde você tenha permissão de escrita.
3. Abra `Juvion/Juvion.exe`.

O pacote inclui o aplicativo e seus componentes. Você não precisa instalar Python. Mantenha todos os arquivos extraídos juntos. Seus livros e preferências ficam na pasta de dados do usuário do Windows.

Estúdio de escrita para contos, romances e ficção, baseado no Writingway. O aplicativo usa Python 3.11 e PyQt5, com suporte previsto para Windows, Linux e macOS.

## Recursos

1. Organização da obra em atos, capítulos e cenas, com versões nomeadas.
2. Dois temas e modo foco com fundo personalizável.
3. Universo com categorias, subcategorias, fichas opcionais, relações e linha do tempo.
4. Assistência no manuscrito para reconhecer fichas e sugerir complementos do Universo.
5. Mapa com imagem e marcadores vinculados às fichas.
6. Modelos de obra, meta de palavras, progresso e revisão literária.
7. Metadados de publicação e exportação DOCX, EPUB, PDF, HTML, Markdown e texto.
8. Assistência opcional com provedores de IA configurados pelo usuário. O editor funciona sem contratar um provedor.

## Código fonte e outras plataformas

Este repositório contém a distribuição executável para Windows x64. Para Linux, macOS, código fonte, instruções para executar com Python e contribuições, acesse o [repositório principal do Juvion](https://github.com/wildfire96/Juvion).

O Juvion deriva do [Writingway](https://github.com/aomukai/Writingway). Os avisos e licenças acompanham o pacote.
